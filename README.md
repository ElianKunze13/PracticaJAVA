# Práctica JAVA 🚀

Repositorio con ejercicios de práctica del lenguaje de programación **Java**. Aquí encontrarás desde conceptos básicos hasta temas más avanzados.

## 📋 Contenido

- **Fundamentos**: Variables, tipos de datos, operadores
- **Control de flujo**: Condicionales, bucles
- **Programación Orientada a Objetos**: Clases, herencia, polimorfismo
- **Estructuras de datos**: Arrays, listas, mapas
- **Excepciones**: Manejo de errores
- **Streams y Lambdas**: Programación funcional
- **Proyectos**: Aplicaciones completas


## ⚙️ Requisitos

- **Java 11** o superior
- **IDE recomendado**: IntelliJ IDEA, Eclipse o Visual Studio Code
- **Compilador**: javac (incluido en JDK)
